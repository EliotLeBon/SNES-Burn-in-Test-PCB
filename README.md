# SNES-Burn-in-Test-PCB
A simple PCB based on M27C801 EPROM for the Burn-in TEST cartridge.

You will need:
- An M27C801 EPROM and programming software.
- A 22uF electrolytic capacitor.
- A 100nF ceramic capacitor.
- An official CIC | PIC10F322 SOT-23-6 | PIC12F629 DIP-8.

If you are using a PIC, you will of course need to program the CIC Key onto it.
